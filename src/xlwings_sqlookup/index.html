SQLookup

The SQLOOKUP function queries the ranges and tables in your workbook with SQL. The SQL engine is SQLite, running locally in xlwings Lite: your data never leaves Excel.

To see SQLOOKUP in action, insert a new sheet with a few examples. Expand the formula bar vertically to see the full formulas.

Syntax

=SQLOOKUP(
  query,
  [alias a], table a,
  [alias b], table b,
  ...
  [parse_dates]
)
  • query: the SQL query as text, e.g., "SELECT * FROM orders", or a reference to a cell that contains it.
  • alias (optional): the table name for the range in the next argument, similar to how LET works. Without an alias, the first range is called a, the second one b, etc.
  • table: a range or Excel table, e.g., A1:C20 or Table1[#All]. The first row must contain the column names.
  • parse_dates (optional): the date columns as comma-separated text, e.g., "order_date, ship_date". The names must match the column names exactly, but case doesn't matter.

The result spills into the neighboring cells, with the column names in the first row. The simplest example is:

=SQLOOKUP("SELECT * FROM a", A1:B10)

Tips

  • Empty cells are NULL and vice versa.
  • Put column names that contain spaces in square brackets: "SELECT [order id] FROM a".
  • Dates are ISO text within the query, e.g., 2024-01-15 00:00:00. Compare them with datetime() or date(), e.g., WHERE date(order_date) = '2024-01-15'.
